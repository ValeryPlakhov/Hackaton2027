## Ответы на вопросы жюри

**Почему без AI?** Кейс допускает AI, но он не обязателен. В критическом контуре важны воспроизводимость и проверяемый AST. AI можно добавить как слой объяснения и предложения патчей, всегда под gate.

**Можно ли доказать эквивалентность тестами?** Для всех программ - нет. Мы доказываем корректность формулы в выбранном шаблоне и отдельно подтверждаем наблюдаемое поведение на тестовых входах. Публично заявляем обе границы.

**Почему не переносите любой метод?** Неявные поля, динамическая диспетчеризация, lock-мониторы и приватные типы делают автоматическую нарезку рискованной. Реализован конкретный перенос с compile check и последующей проверкой поведения.

**Зачем Big O с оговорками?** В общем Java статически вывести точные границы всех циклов невозможно. Эвристика полезна для навигации, если не выдавать её за доказательство.

**Насколько безопасен runner?** Trusted local - для собственных исходников, дочерняя JVM не песочница. Docker runner создаёт отдельный контейнер без сети с лимитами; этот путь требует проверки в среде с Docker. Публичный сервис потребует также изоляции компиляции и отдельной worker-ноды.

**Что проверено на монолите?** 1052 строки, 51 метод, AST, применение оптимизации, успешная компиляция обеих версий и дифференциальный прогон. Статистические методы реально вызываются из main.
