# Аудит исходников

Генерация: `python tests/source_audit.py`.

Подсчёт физических и непустых строк, включая комментарии. Это метрика объёма, не качества.

| Язык | Файлы | Строки | Непустые |
|---|---:|---:|---:|
| CSS | 1 | 4457 | 3935 |
| HTML | 2 | 539 | 531 |
| Java | 21 | 4748 | 4497 |
| JavaScript | 33 | 5988 | 5683 |
| Python | 9 | 1032 | 918 |
| **Продукт** | **50** | **14835** | **13801** |
| **Тесты и инструменты** | **16** | **1929** | **1763** |
| **Всего** | **66** | **16764** | **15564** |

Не включены зависимости, runtime, сборка, JSON, записи прогонов, примеры, документация, SVG и копии Java в web/samples.

CSS показан отдельно. Продукт превышает 12 000 непустых строк и без тестов. Разбивка по каждому файлу: `source-audit.json`.
