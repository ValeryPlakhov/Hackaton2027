# Java Blueprints

Рабочая визуальная среда для кейса AXENIX: загрузка Java, настоящий AST, граф, диагностика, правка узлов, генерация исходников, оптимизация, декомпозиция и автоматическое сравнение поведения на JVM.

## Быстрый запуск на этом компьютере

Дважды щёлкните **start-local.cmd**, затем откройте **http://localhost:8080**. Переносимый JDK уже находится в `.runtime/`. Этот режим предназначен для ваших доверенных исходников: дочерняя JVM не является песочницей ОС.

Альтернативно из PowerShell:

```powershell
.\start.ps1 -TrustedLocal
```

Без `-TrustedLocal` анализ и редактирование работают, выполнение Java отключено. Флаг `-Docker` использует отдельный контейнер для каждого запуска; заранее выполните `docker pull eclipse-temurin:21-jre`. Требуется Docker Desktop, он не входит в проект.

## Запуск из архива на другом компьютере

1. Установите JDK **21 или новее** (именно JDK, не JRE), задайте `JAVA_HOME` либо добавьте `java` и `javac` в `PATH`.
2. Windows: `start-local.cmd`. Linux/macOS: `BLUEPRINTS_RUNNER=local sh start.sh`.
3. Откройте `http://localhost:8080`.

Ни Maven, ни npm, ни ключи API, ни платные модели не нужны. В архив не включён JDK размером около 200 МБ.

Контейнерный запуск: `docker compose up --build`. Порт опубликован только на loopback. Контейнер сервиса ограничивает доступ к хосту, но все пользовательские программы внутри него разделяют контейнер с сервером; это **не** изоляция между недоверенными пользователями. Для отдельных контейнеров используйте сервер на хосте с `-Docker`. Docker-путь подготовлен, но на данном компьютере не проверен: Docker отсутствует.

## Полный сценарий за 3 минуты

1. Откройте встроенный `PairAnalyzer.java`, выберите `countPairs`. Увидите вложенные циклы и `O(n^2)`.
2. Нажмите **Применить оптимизацию**. Тело метода заменится на индекс частот; исходник и граф обновятся.
3. Нажмите **Проверить поведение**. Обе версии реально компилируются и исполняются на восьми входах.
4. Дважды нажмите узел условия в `classify`, замените `(n == 0)` на `(n == 1)` и повторите проверку. Gate обнаружит изменение поведения.
5. Отмените правку. Выберите оптимизированный `countPairs` и нажмите **Декомпозиция**: появится `BlueprintFunctions.java`, исходный метод делегирует вызов. Запустите gate снова.
6. Нажмите **Экспорт**: получите исходники, эталон, входы и JSON-отчёт в одном ZIP.
7. Загрузите `examples/LargeMonolith.java`: **1052 строки**, 51 метод; статистические функции реально вызываются. Повторите оптимизацию и gate.

Подробный сценарий и ответы жюри: [docs/DEMO.md](docs/DEMO.md).

## Возможности и честные границы

| Возможность | Реализация |
|---|---|
| Язык Java | Стандартный `javac --release 21`: классы, интерфейсы, поля, методы, конструкторы, управляющие конструкции, исключения и стандартная библиотека |
| Бонусный scope | record, enum, дженерики, лямбды, Stream: компилируются и сохраняются |
| Граф | Структурная проекция AST с ветвями if/switch, петлями, break/continue и консервативными связями try/catch |
| Код → граф | Авторазбор после ввода с задержкой 750 мс, ручное обновление, выбор файла и метода |
| Граф → код | Правка инструкций, условий и выражений в цикле; вставка/удаление инструкций; точечная замена по UTF-16 span |
| Сохранение исходников | Нетронутые символы, комментарии и форматирование остаются побайтно в строковом представлении; UTF-8 экспорт |
| Диагностика | Вложенные циклы, длинный метод, пустой catch, накопление += в цикле, сравнение строки по ссылке |
| Big O | **Эвристика** по вложенности, с явно указанными допущениями. Вызовы, размер вывода, реальные границы циклов не учтены; рекурсия помечена неизвестной |
| Автооптимизация | Узкий проверяемый AST-шаблон подсчёта упорядоченных равных пар в `int[]` с `int`-счётчиком |
| Декомпозиция | Независимый static-метод переносится в helper-файл, исходная сигнатура сохраняется; зависимость от полей/контекста отклоняется при компиляции |
| Quality gate | Раздельная сборка и JVM для обеих версий; точные stdout, stderr, exitCode; таймаут и переполнение вывода всегда FAIL |
| Тесты | 22 интеграционных сценариев, включая случайные входы и намеренные нарушения контракта |

Это не полноценный Java IDE/отладчик. Произвольное перетягивание рёбер и восстановление любого графа в Java отсутствуют: граф редактируется через структурированные операции. Перетаскивание узлов меняет только раскладку. Метки и сложные выражения сохраняются непрозрачными узлами; exception-flow и переходы через finally показываются структурно, без полного анализа исключений. Вставка возле объявления переменной запрещена, чтобы не менять область видимости скрытым образом.

Оптимизатор не обещает автоматически исправить любой монолит. Он распознаёт конкретную чистую форму, отказывает при дополнительных эффектах и требует проверки результата. Истинность алгоритмической формулы не означает полной эквивалентности при исчерпании памяти: новая версия использует O(k) дополнительной памяти.

```powershell
python tests/test_api.py
```

На этом компьютере Python доступен по пути `C:\Users\NoteBook\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`.

Результат: `docs/test-summary.json`. Записанный реальный прогон демопримера: `docs/behavior-report.json`. Пересоздать данные для статического обзора: `python tests/prepare_demo.py`. Монолит воспроизводится через `python tests/generate_monolith.py`.

## Архитектура

```
web/                         HTML + CSS + JavaScript, без сборки и CDN
    ↓ JSON API               same-origin, loopback по умолчанию
BlueprintServer              маршруты, лимиты запросов, статические файлы
JavaModel                    JavacTask.parse() + SourcePositions
    ├── GraphBuilder         структурный граф и редактируемые spans
    ├── Analyzer             привязанные к строкам диагностики и эвристики
    └── Transformations      редактирование, AST-шаблон, helper extraction
Runner                       javac → отдельные class dirs → отдельные JVM
    ↓                        stdin / stdout / stderr / exitCode
Quality gate                 точное сравнение + отчёт JSON
```

Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), матрица требований: [docs/SCOPE.md](docs/SCOPE.md).

## Веб-обзор и полная версия

Развёрнутый Sites содержит **интерактивный обзор** на сохранённых реальных AST и результатах. Он явно помечен «без JVM»: произвольный Java-код на нём не исполняется. Полная версия запускается локально или в контейнере. Это ограничение серверной среды Sites/Cloudflare Workers, а не замена тестов фиктивным зелёным статусом.

Демо-данные не содержат пользовательских файлов. Новое развёртывание приватное для владельца. Для судей используйте локальную демонстрацию или самостоятельно предоставьте им доступ к хостингу полной версии.

## API

Все изменения через `POST application/json`.

- `/api/analyze`: `{source}` → AST-модель, методы, графы, диагностики.
- `/api/edit`: `{source, methodId, nodeId, code, action}` → новый исходник и модель. `action`: replace / before / after / delete.
- `/api/optimize`: `{source, methodId}` → новый исходник или отказ.
- `/api/extract`: `{files, fileName, methodId}` → исходный файл и helper.
- `/api/compile`: `{files}` → результат сборки.
- `/api/compare`: `{original, candidate, inputs}` → две сборки и отчёт тестов.
- `/api/health`: GET → JDK, runner mode.

`files` - объект вида `{"Main.java":"..."}`. До 30 файлов и 500000 символов на проект, 30 входов по 32768 символов. Java-код запускается с 96 МБ heap; trusted local: 2.5 с на запуск, Docker: 7 с; сборка: 15 с; stdout/stderr: до 64 КиБ каждый. Одновременно до двух сравнений. Временные каталоги удаляются после завершения.
